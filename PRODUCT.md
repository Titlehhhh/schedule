# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Студенты заочного отделения колледжа. Основной сценарий — открыть сайт с телефона
между делами и за пару секунд понять: что идёт сейчас, что сегодня, что завтра,
и что надо сдать по заданиям. Вторичный сценарий — заочно, заранее: посмотреть
неделю целиком или найти срок сдачи конкретной работы.

## Product Purpose

Статический сайт с расписанием занятий и списком заданий по дисциплинам.
Существует потому, что исходная таблица колледжа неудобна: занятия чередуются
двумя учебными неделями, и по таблице нельзя быстро ответить на вопрос
«что у меня завтра». Успех — студент открыл сайт и сразу знает, куда идти
и что горит.

## Positioning

Расписание перенесено из таблицы вручную и пересчитано по академическим
неделям: сайт сам отвечает на вопрос «какая сейчас неделя — первая или
вторая» и подставляет нужную половину расписания. Работает офлайн, без
бэкенда и без регистрации, на одной странице без перезагрузок.

## Operating Context

Заочное отделение: студент не ходит на каждое занятие, у него своя
текучка. Задания приходят от преподавателей по каналам, сроки сдачи жёсткие,
часть работ имеет формальный отчёт (реферат, лабораторная, отчёт).
Время считается в локальной зоне браузера, часовой пояс Екатеринбурга.

## Capabilities and Constraints

- Чистые HTML + CSS + JavaScript, без сборщика и зависимостей; публикация
  через GitHub Pages.
- Все пути относительные: сайт живёт в подкаталоге `/schedule/`.
- Офлайн-режим: service worker кэширует все файлы сайта.
- Размер сайта держится десятками килобайт.
- Данные лежат в одном файле `data.js`; логика дат — в `core.js`, DOM — в `app.js`.
- Название группы не должно появляться ни в интерфейсе, ни в исходниках,
  ни в истории git.
- Отметки о выполнении заданий хранятся только в браузере пользователя
  (localStorage), без синхронизации и без отправки куда-либо.

## Brand Commitments

- Название продукта: «Расписание занятий», подпись — «заочное отделение».
- Язык интерфейса — русский, обращение на «вы».
- Спокойный рабочий тон: без мотивационных цитат, без смайликов и восклицательных
  знаков в системных сообщениях.
- Устоявшийся вид сайта (зелёный акцент, карточки со скруглением, тёмная тема)
  сохраняется; новый раздел наследует его, а не вводит вторую визуальную систему.

## Evidence on Hand

- `data.js` — расписание, звонки, границы семестра: перенесено из таблицы
  колледжа и сверено по увеличенным кропам.
- `test/core.test.js` — 80 проверок логики дат и недель.
- `test/e2e.js` — 43 проверки вёрстки в реальном браузере.
- Настоящих данных по заданиям пока нет: список заданий — заготовка, которую
  заполняет сам студент. Ничего выдуманного о работах, преподавателях и сроках
  показывать нельзя.

## Product Principles

1. Две секунды: ответ на «что сейчас и что дальше» должен быть виден без
   прокрутки и без чтения.
2. Правда из источника: любые числа, сроки и названия берутся из таблицы
   или вводятся человеком, ничего не придумывается.
3. Расписание и задания — один продукт: переход между ними в один клик,
   одна шапка, одна тема.
4. Локальность: приватные отметки остаются в браузере, ничего не улетает.
5. Читаемость важнее украшения: контраст, размер шрифта, отсутствие
   горизонтальной прокрутки на 320 px.

## Accessibility & Inclusion

Мобильный-first, работа без мыши. Клавиатурная навигация и видимый фокус,
`aria-live` для изменяющегося статуса, доступные имена у иконок-кнопок,
контраст текста не ниже 4.5:1, уважение `prefers-reduced-motion` и
`prefers-color-scheme`.
