# AGENTS.md — инструкция для агента по этому репозиторию

Прочитай целиком, прежде чем что-то менять. Здесь собрано то, что иначе
приходится выяснять заново: что за проект, где что лежит, как читать
исходную таблицу и какие грабли уже наступали.

---

## 1. Что это

Статический сайт с расписанием занятий одной группы колледжа (заочное
отделение). Ни бэкенда, ни сборщика, ни зависимостей — чистые
HTML + CSS + JavaScript, публикуется на GitHub Pages через Actions.

Главная задача сайта: за две секунды показать, **что идёт сейчас, что
сегодня, что завтра** — с учётом того, что занятия чередуются двумя
неделями (1-я и 2-я учебная неделя).

Технические характеристики:

| | |
|---|---|
| Публикация | <https://titlehhhh.github.io/schedule/> |
| Репозиторий | <https://github.com/Titlehhhh/schedule> (public) |
| Сборка | не требуется, `git push` → Actions → Pages |
| Офлайн | service worker (`sw.js`), кэширует 8 файлов |
| Размер сайта | ~70 КБ, 16 файлов в репозитории |

**Название группы нигде не должно появляться** — ни в интерфейсе, ни в
исходниках, ни в истории git, ни в имени репозитория. Причина — чтобы по
сайту нельзя было понять, чья это группа. Проверка в разделе 9.

| `core.js` | Чистая логика без DOM: арифметика недель, выборка занятий, статус «сейчас», экспорт `.ics` | логика дат/недель/экспорта |
| `app.js` | Рендер DOM и обработчики | вёрстка/поведение |

| `index.html` | Каркас страницы | структура |
| `sw.js` | Service worker: офлайн-кэш | при добавлении новых файлов в кэш |
| `manifest.webmanifest`, `favicon.svg` | PWA | метаданные |
| `serve.js` | Мини-сервер для локального просмотра | — |
| `tools/zoom.py`, `tools/grid.py` | Разбор исходной картинки таблицы | при разборе новой таблицы |

Правило слоёв: `data.js` не знает про DOM, `core.js` не знает про DOM,
`app.js` не содержит логики дат. Не смешивай — иначе тестируемое ядро
разъедется.

## 4. ГЛАВНОЕ: как читать исходную таблицу

**Это место, где уже была допущена ошибка.** В первой версии проекта
преподаватель был записан как «Чубунина» вместо «Чучулина», а кафедра —
название кафедры — с «З» вместо «Э». Обе ошибки выросли из того, что текст читался по
превью картинки, а не по увеличенному кропу.

### Правило

> Никогда не переноси текст из превью. Каждую строку вырезай из
> оригинала, увеличивай в 6–7 раз и читай посимвольно. Сомнительные
> буквы («Э»/«З», «у»/«б», «а»/«о») — перечитывай, пока не станет
> однозначно.

### Как это делается

```bash
# 1) увеличенный кроп нужной строки (x0 y0 x1 y1 — координаты в оригинале)
python tools/zoom.py schedule.png 150 168 500 190 7

# 2) понять сетку таблицы: полноширинные границы ячеек и половинки
python tools/grid.py schedule.png
```

`tools/grid.py` печатает по каждому дню: границы строк, где внутри строки
проходит разделитель (это граница «1-я неделя / 2-я неделя») и сколько
в ячейке строк текста. `tools/zoom.py` кладёт увеличенный кроп в
`.work/crops/`.

### Чек-лист проверки после разбора

- [ ] все 9 преподавателей сверены по кропам 6–7×;
- [ ] все аудитории сверены так же;
- [ ] отдельно перепроверены название кафедры (первая буква — «Э», не «З») и `Чучулина` (не `Чубунина`);
- [ ] вид занятия: `лек` / `пр` / `лаб` — сверять в кропе, а не по памяти;
- [ ] каждый класс в таблице сопоставлен с записью в `data.js` (время, день, неделя, вид, преподаватель, аудитория).

## 5. Модель данных (`data.js`)

```js
{ day: 'wed', time: '13:20', weeks: [2],
  subject: 'Профессиональный иностранный язык',
  kind: 'пр', teacher: 'доц. Хабибрахманова Ф.Р.', room: '116 к.А' }
```

* `day` — `mon` | `tue` | `wed` | `thu` | `fri`
* `time` — начало пары, `HH:MM`
* `weeks` — в каких неделях идёт пара: `[1]`, `[2]` или `[1, 2]`
* `kind` — `лек` | `пр` | `лаб`
* `room`, `teacher` — необязательные
* код кафедры не хранится: на сайте нельзя публиковать по группе

### Как строки таблицы превращаются в записи

* Каждая ячейка разделена на две половинки: **верхняя = 1-я неделя,
  нижняя = 2-я неделя**. Если половинка пустая — пары в этой неделе нет.
* Ячейка без разделителя (одна целиком) — пара идёт **в обе недели** →
  `weeks: [1, 2]`.
* В понедельнике и вторнике **время в ячейке не совпадает со строкой
  таблицы** — строки там сдвинуты. Верь подписанному в ячейке времени
  (13:20, 15:00, 16:40, 18:20), а не подписи строки. В среде, четверге
  и пятнице подписи нет — там время = строка таблицы.
* Конец пары считается по звонкам (`bells`): следующий звонок после начала.

### Задания (`data.js` → `assignments`)

```js
{ id: 'bd-lab-1', subject: 'Введение в большие данные',
  title: 'Лабораторная работа №1', type: 'лабораторная',
  due: '2026-10-23', what: 'Что сделать…', how: ['Шаг 1', 'Шаг 2'],
  criteria: 'Критерии…', teacher: 'доц. Шалов В.А.', link: '' }
```

* `id` — латинский уникальный ключ: на нём держится отметка «сделано»
* `subject` — точное название дисциплины из `lessons[].subject`
* `title`, `type`, `due` (`ГГГГ-ММ-ДД`) — обязательные
* `what`, `how`, `criteria`, `teacher`, `link` — необязательные, пустые не выводятся
* логика сроков и статусов — в `core.js` (`assignmentState`, `groupAssignments`,
  `buildTasksICS`), рендер — в `app.js`

Отметки «сделано» лежат только в `localStorage` (ключ `schedule-tasks-done`)
и никуда не отправляются.

### Настройки семестра

| Поле | Значение | Смысл |
|---|---|---|
| `semesterStart` | `2026-09-01` | якорь отсчёта недель: неделя, содержащая эту дату — первая |
| `classesStart` | `2026-09-01` | первый день занятий; раньше сайт показывает «занятия ещё не начались» |
| `semesterEnd` | `2026-12-31` | конец семестра; влияет на экспорт `.ics` и на границу листания недель |
| `swapWeeks` | `false` | если в колледже 1-я неделя — **нижняя** половинка, поставь `true` |

Число недели: `округ((понедельник недели − понедельник якоря) / 7) + 1`,
нечётная → 1-я неделя, чётная → 2-я. **21.10.2026 = учебная неделя 8 = 2-я
неделя.** Проверка: в шапке таблицы колледжа написано «начало занятий с
2 ноября — 2 неделя», и 2 ноября при таком отсчёте действительно 2-я
неделя — якорь подтверждается.

В подвале страницы есть настройки (дата начала, перестановка недель) —
они сохраняются в `localStorage` и перекрывают `data.js`.

## 7. Грабли, которые уже наступали

### 7.1. PowerShell ломает UTF-8

`Get-Content`/`Set-Content` в Windows PowerShell 5.1 читают и пишут в
ANSI-кодировке → русский текст превращается в мусор (`Р°СЃРїРёСЃР°РЅРёРµ`).
**Никогда** не правь эти файлы через `Get-Content`/`Set-Content`.
Используй:

* инструмент редактирования агента (edit/write);
* либо Python: `io.open(path, encoding='utf-8').read()` / `.write()`;
* либо PowerShell 7 (`pwsh`), где `Get-Content -Encoding utf8` корректен.

### 7.2. Headless Edge и браузер пользователя

Первый запуск headless Edge был **без `--user-data-dir`** — он зацепился за
обычный профиль и закрыл окно браузера пользователя. С тех пор:

* **всегда** отдельный профиль: `--user-data-dir=$env:TEMP/<случайное>`;
* после прогона **обязательно** снести дерево процессов:
  `taskkill /pid <pid> /T /F` и удалить профиль;
* пользовательский Edge (`profile-directory=Default`) не трогать никогда.

### 7.3. Headless Edge игнорирует `--window-size` для вёрстки

`--window-size` задаёт размер PNG, но **layout viewport остаётся 500 px** —
скриншот «шириной 390 px» на самом деле рендерится в 492 px и обрезается.
Чтобы проверить вёрстку на конкретной ширине, есть харнесс:

```
http://127.0.0.1:8000/_mob.html?w=390&h=1400
```

(`_mob.html` кладёт сайт в iframe заданной ширины; файл в `.gitignore`,
при необходимости пересоздать — 15 строк).

### 7.4. `.ics` — четыре правила, которые уже ломались

* **Диапазон экспорта = границы семестра**, а не якорь отсчёта. Иначе смена
  «начала занятий» в подвале тихо выбрасывала 27–100 % пар.
* `TZID=Europe/Yekaterinburg` + блок `VTIMEZONE`; плавающее время без TZID
  клиенты читают по-разному.
* Строки ≤ 75 **октетов** (кириллица — 2 байта, режем по байтам), файл
  заканчивается CRLF (RFC 5545).
* UID — ASCII и уникальный: `дата-время-день-вид`.

### 7.5. Чётность недель для отрицательных номеров

В JS `-9 % 2 === -1`, а не `1`. Поэтому `academicWeekNo % 2 === 1 ? 1 : 2`
ломало чередование до начала семестра. Правильно:
`(n % 2 === 0) ? 2 : 1` — корректно и для отрицательных `n`.

### 7.6. `[hidden]` против `display`

`.week__hint` имеет `display: flex` — атрибут `hidden` без
`[hidden] { display: none !important }` не работал, и пустая плашка висела
на странице. Правило добавлено глобально — не убирай.

### 7.7. Live-регион нельзя перезаписывать целиком

`aria-live` — на `.status__main`. Если перезаписывать его `innerHTML` каждые
20 секунд, скринридер перечитывает весь блок. Поэтому в `app.js` есть
`state.statusKey`: содержимое живой области обновляется **только при
смене статуса**, а таймер меняет лишь таймер и часы (вне live-региона).

## 8. Как поменять расписание (чек-лист)

1. Получить новую картинку таблицы.
2. Разобрать её: `tools/grid.py` → структура ячеек; `tools/zoom.py` → текст
   построчно, посимвольно.
3. Переписать `lessons` в `data.js` (формат — раздел 5). Не забудь
   про `weeks` и про подписанное время.
   неделям, конкретные предметы/времена, число событий в `.ics`.
4. Проверка в реальном браузере — отдельным прогоном в фоновом окне.
5. Скриншот на 320 и 390 px (через `_mob.html`) — вёрстка не поехала.
8. `git commit` + `git push`, дождаться воркфлоу, открыть живой сайт.
