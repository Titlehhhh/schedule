# Расписание занятий

Статический сайт с расписанием занятий (заочное отделение).
Показывает, что идёт сейчас, что сегодня, что завтра, и полное расписание
на неделю с учётом чередования **1-й и 2-й учебной недели**.
Вторая вкладка — **«Задания»**: список работ по дисциплинам со сроками,
описанием, шагами и отметками «сделано» (отметки хранятся только в браузере).

Никаких сборщиков, зависимостей и бэкенда: чистые HTML + CSS + JavaScript.
Работает офлайн и из коробки на GitHub Pages.

```
index.html   разметка
styles.css   стили (мобильный-first)
data.js      ← расписание и настройки недель (единственное, что нужно править)
core.js      логика: даты, недели, выборка занятий, экспорт в .ics
app.js       рендер интерфейса
test/        тесты логики (node, без зависимостей)
tools/       разбор исходной таблицы (zoom.py — кропы, grid.py — сетка)
```

Для ИИ-агентов: **[AGENTS.md](AGENTS.md)** — что за проект, как читать
исходную таблицу посимвольно, какие грабли уже наступали.
`CLAUDE.md`, `GEMINI.md` и `.github/copilot-instructions.md` ссылаются на него.

## Как запустить локально

Нужен любой статический сервер (файловый протокол не подойдёт из-за `localStorage`):

```bash
node serve.js 8000     # или: python -m http.server 8000
# затем откройте http://localhost:8000
```

## Как опубликовать на GitHub Pages

1. Создай репозиторий и закинь туда эти файлы.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Всё: в репозитории уже лежит `.github/workflows/pages.yml`, он собирает и
   публикует сайт при каждом пуше в `main`.

Альтернатива без Actions: **Settings → Pages → Source: Deploy from a branch**,
ветка `main`, папка `/ (root)`. Файл `.nojekyll` в корне нужен, чтобы GitHub
не прогонял сайт через Jekyll.

## Как поправить расписание

Всё в `data.js`:

```js
{ day: 'wed', time: '13:20', weeks: [2],
  subject: 'Профессиональный иностранный язык',
  kind: 'пр', teacher: 'доц. Хабибрахманова Ф.Р.', room: '116 к.А', room: '116 к.А' }
```

* `day` — `mon` / `tue` / `wed` / `thu` / `fri`;
* `time` — начало пары по звонку;
* `weeks` — в каких неделях идёт пара: `[1]`, `[2]` или `[1, 2]` (в обе);
* `kind` — `лек` / `пр` / `лаб`;
* `room`, `teacher`, `dept` — необязательные поля.

Занятия сортируются автоматически, конец пары считается по расписанию звонков
(`bells` в том же файле).

## Как добавить задания

Тоже в `data.js`, в массив `assignments`:

```js
{ id: 'bd-lab-1',
  subject: 'Введение в большие данные',
  title: 'Лабораторная работа №1',
  type: 'лабораторная',
  due: '2026-10-23',
  what: 'Что нужно сделать — одним абзацем.',
  how: ['Шаг 1', 'Шаг 2', 'Шаг 3'],
  criteria: 'Критерии проверки.',
  teacher: 'доц. Шалов В.А.',
  link: 'https://…' }
```

* `id` — латинский уникальный ключ: на нём держится отметка «сделано»;
* `subject` — точное название дисциплины из `lessons[].subject` (по нему
  находится следующая пара по этой дисциплине);
* `title`, `type`, `due` — название, вид работы и срок сдачи (`ГГГГ-ММ-ДД`);
* `what`, `how`, `criteria`, `teacher`, `link` — необязательные.

Пустые поля просто не выводятся. Сроки можно выгрузить в календарь кнопкой
«Сроки в календарь» — это отдельный `.ics` с событиями на весь день.
Отметка «сделано» хранится в `localStorage` браузера (ключ
`schedule-tasks-done`), никуда не отправляется.

## Как считается номер недели

Занятия чередуются: **1-я неделя, 2-я неделя, 1-я, 2-я…**

Первая учебная неделя — та, внутри которой лежит `semesterStart` в `data.js`
(по умолчанию `2026-09-01`). Недели считаются с понедельника:

```
учебная неделя = round((понедельник недели − понедельник первой недели) / 7) + 1
нечётная → 1-я неделя, чётная → 2-я неделя
```

Для 21 октября 2026 получается учебная неделя 8 → **2-я неделя**.

Если в вашем колледже отсчёт другой, поменяйте `semesterStart` в `data.js`
или задайте дату прямо в подвале страницы («Как считается номер недели») —
выбор сохранится в браузере.

Отдельно в `data.js` есть `classesStart` — первый день, когда идут занятия.
До него сайт показывает «занятия ещё не начались», а не пары из будущего.
По умолчанию он совпадает с началом семестра; если занятия начинаются
2 ноября, поставьте `classesStart: '2026-11-02'` (кнопка для этого есть
в подвале страницы).

## Экспорт в календарь

Кнопка «В календарь» отдаёт `.ics` со всем семестром: каждая пара уже разложена
по конкретным датам с учётом чередования недель, время указано в зоне
Europe/Yekaterinburg. Импортируется в Google Calendar, Outlook, Яндекс.Календарь.

## Тесты

```bash
npm test        # или: node test/core.test.js  — логика недель и расписания
npm run test:e2e  # рендер в headless Chrome/Edge: вёрстка, переполнения, ошибки
```

Логика: арифметика недель (включая недели до начала семестра), выборка занятий
по дням, отсутствие накладок пар, логика «что идёт сейчас», границы семестра,
корректность `.ics` (TZID, уникальные UID, CRLF), смена якорной даты.

E2E: страница рендерится в браузере на ширине 390 px в шести состояниях
(идёт пара / до пары / пары закончились / день без пар / выходной / второй
день) — проверяется отсутствие горизонтального скролла и переполненных
элементов, ожидаемый текст состояния и отсутствие `undefined`/`NaN`.
Тест пропускается, если браузер не найден; запускает headless Chrome/Edge
с отдельным профилем в `%TEMP%` и закрывает его после прогона.

## Замечания по исходной таблице

* В оригинале каждая ячейка с двумя подстроками — это «1-я неделя» (верхняя
  подстрока) и «2-я неделя» (нижняя). Ячейка, разделённая на две части, но
  содержащая одну пару, идёт в обе недели. Если у вас наоборот — поставьте
  `swapWeeks: true` в `data.js` или включите галочку в подвале страницы
  («Как считается номер недели»).
* В понедельнике и вторнике время занятий отличается от строки таблицы и
  подписано прямо в ячейке (13:20, 15:00, 16:40, 18:20) — в `data.js`
  проставлено именно подписанное время.
* Обозначения: `лек` — лекция, `пр` — практическое занятие, `лаб` — лабораторная.
* `semesterEnd` в `data.js` — предполагаемая дата конца семестра, её стоит
  поправить под реальный календарь занятий. На неё влияет и экспорт в `.ics`.
* Аудитории даны так, как в оригинале: `403 к.А`, `416 к.А`, `414 к.А`,
  `119 к.А`, `120 к.А`, `116 к.А`, `400 к.А`, `101 к.В`, `66 к.Д`.
  Название группы на сайте неукужно: сайт общий для всех, кодка кафедры и номер группы не публикуются.
